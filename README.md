# RNA-Seq арқылы дифференциалды гендерді талдау (Жоба атауы)

## 📌 Жобаның Мақсаты
Рак клеткаларындағы гендердің экспрессиясын бақылау және сау клеткалармен салыстыру.

## 📊 Дереккөздер (Data)
- **NCBI GEO accession:** GSEXXXXXX
- **Деректер түрі:** RNA-Seq raw count matrix

## 🛠 Қолданылған Құралдар мен Тілдер
- **Тіл:** R (v4.3) / Python
- **Пакеттер:** DESeq2, ggplot2, pheatmap, tidyverse
- **Орта:** Linux Bash, RStudio

## 🚀 Нәтижелер (Results)
- Дифференциалды экспрессияланған гендер анықталды (p-adj < 0.05).
- Heatmap және Volcano Plot арқылы визуализация жасалды.
